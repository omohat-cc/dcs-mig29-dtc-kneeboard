SPO-15 status chips

Pill-style fixed-width chip (min-width 90 px, height 36 px, no radius). Centered text is Barlow Condensed 800 18 px tracked 0.12em UPPER. Three states:

StateFillTextBorderNotes
Lock#FFFFFF#C1273B1.5 px #C1273BOutlined red, bold weight. Highest-priority threat — reads at glance without dominating.
On#FFFFFF#1F8A3F1.5 px #1F8A3FOutlined green. Active but not critical.
Off#FFFFFF#8A8E951.5 px #8A8E95Muted gray, no fill.

Empty-state pattern

When a section has no entries the body area shows: a top hatched rule (6px-on/6px-off, 1 px, color #C8C2B6), then centered text NO CONFIG in Barlow Condensed 800 32 px #8A8E95 tracked 0.16em UPPER, optional hint “NOT PROGRAMMED” in Barlow 500 14 px tracked 0.12em #8A8E95, then a bottom hatched rule. The header band is unchanged so muscle memory holds.

Fonts

Barlow Condensed (display, 700/800), Barlow (body, 500/600/700), JetBrains Mono (data, 500/700) — all available on Google Fonts. Substitute with Oswald / Open Sans / Roboto Mono if exact families aren't bundled with the Pillow generator. All numeric data uses font-variant-numeric: tabular-nums to keep frequency columns aligned.
